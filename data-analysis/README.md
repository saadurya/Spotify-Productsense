# Spotify Listening Data Analysis

## Objective

Analyze Spotify listening behaviour to identify patterns that could inform product decisions for college-student users.

## Questions

This analysis will explore:

- How listening behaviour differs between users
- Which listening patterns appear most frequently
- Whether different behavioural groups can be identified
- What product opportunities may emerge from the data

## Important Note

The analysis will use a publicly available or simulated dataset for learning purposes.

The findings should not be interpreted as representative of Spotify's actual internal user population.

## Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
