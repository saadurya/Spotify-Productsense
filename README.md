# Spotify Product Sense Lab

> An independent product sense learning project focused on identifying and prioritizing opportunities to improve Spotify for college students.

## Challenge

**How might we improve Spotify for college students?**

## Objective

Identify meaningful problems faced by college students while using Spotify and determine which problem is worth solving.

## Scope

This project focuses on product discovery and product sense rather than building the product.

## Learning Goals

- Understand the target user
- Identify and segment users
- Discover user needs and pain points
- Define the problem clearly
- Identify product opportunities
- Prioritize opportunities
- Propose an MVP
